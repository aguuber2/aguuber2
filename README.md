### 🚀 Featured Project: [Mathing](https://mathing.co/)

**[Mathing.co](https://mathing.co/)** is a fast-paced, minimalist 60-second daily speed arithmetic game designed to make mental math practice engaging, quick, and habit-forming.

- ⏱️ **60-Second Sprint:** Solve as many equations as you can against the clock.
- 🌍 **Synchronized Daily Puzzle:** Every player in the world gets the exact same seeded puzzle each day.
- ⚡ **Zero Bloat & Fast:** Instant load times, no sign-ups or paywalls, and smooth play across desktop and mobile.
- 📈 **Streaks & Stats:** Tracks daily streaks, high scores, and accuracy percentages.
