### 🧮 Featured Project: [Mathing](https://www.mathing.co/)

**[Mathing](https://www.mathing.co/)** is a free, browser-based mental math game featuring a shared daily 60-second challenge and on-demand practice.

- ⚡ **60-Second Daily Sprint:** Solve as many arithmetic equations (+, −, ×, ÷) as you can against the clock.
- 🌍 **Shared Daily Seed:** Every player worldwide gets the exact same sequence of equations each day, resetting at midnight.
- 🎯 **Single-Digit Flow State:** Every equation resolves to an integer from 1 to 9 with instant auto-advance—no Enter key required.
- 🔓 **Zero Friction:** 100% free in the browser—no ads, no sign-ups, no app downloads.

👉 **[Play Today's Daily Puzzle at mathing.co](https://www.mathing.co/)**
